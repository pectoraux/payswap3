# UI-001 — Shared Product Shell and Navigation Grammar

**Status:** READY  
**Depends on:** none  
**One branch/PR:** required

## Objective
Complete a calm, consistent PaySwap application shell using the UX contract: Home, Activity, Network, Evidence, More, plus persistent Ask PaySwap; role adaptation changes emphasis, not the navigation grammar.

## Acceptance
- Authenticated product uses one shared navigation grammar across supported roles.
- Ask PaySwap is persistently reachable from the shell.
- Public entry keeps Explore, Join waitlist, and Sign in distinct.
- Mobile navigation follows the compact UX model.
- Existing authentication/role gates continue to work.
- No protocol semantics or financial authority is changed.
- Automated tests cover shell navigation and role access.
- Architect verifies exact PR head and repository state before merge.
