# Implementation Protocol

1. Architect validates repository and activates an eligible Work Order/wave with an exact base revision and assurance profile.
2. Each Z.ai worker receives a repository-native execution context and one Work Order.
3. Critical work establishes red/discrimination proofs before green implementation where practical.
4. Worker implements the smallest conforming change inside owned surfaces.
5. Worker records exact revision, verification, dogfooding/conformance, limitations and scope audit.
6. Architect reviews the exact head and decides approve, changes requested, or architecture change required.
7. Architect alone merges.
8. Post-merge finalization records the authoritative Git merge and recomputes derived state.
9. Integration gates run only after their required inputs are merged.
