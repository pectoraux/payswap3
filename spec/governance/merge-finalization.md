# Post-Merge Finalization Protocol

Architect merge is the completion fact. Finalization is bookkeeping.

Required checks: actual merged PR; Architect attribution; Work Order↔PR↔merge binding; approved-head/merge-tree policy; program-state completion; `mergedAs`; obsolete handoff removal; derived-state recomputation; preserved historical evidence.

If Git proves a merge while canonical state says in-flight, governance is RED until reconciled. The reconciler never invents approval or completion.
