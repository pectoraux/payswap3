# PaySwap Architecture v0.1

This directory is the conceptual and constitutional source for the first implementation generation.

## Documents

- `constitution.md` — purpose, invariants, boundaries, and non-negotiable rules.
- `canonical-object-model.md` — canonical object families and relationships.
- `command-event-model.md` — commands, events, system triggers, and causal semantics.
- `ownership-lifecycle.md` — ownership, authority, custody, domains, lifecycle and archival.
- `ledger-posting-model.md` — monetary accounting and posting rules.
- `interoperability.md` — endpoint resolution, canonical messages and external adapters.
- `simulation.md` — one-machine/many-worlds simulation, replay, forecast and shadow semantics.
- `extensions.md` — composable capabilities, developer economics, authority tiers and isolation.
- `security-risk.md` — identity, authentication, fraud, risk, compliance, privacy and resilience.
- `governance.md` — protocol governance, upgrade, federation and institutional boundaries.
- `implementation-principles.md` — engineering rules derived from the architecture.
- `architecture-lock.md` — immutable architecture lock and permitted change mechanism.
